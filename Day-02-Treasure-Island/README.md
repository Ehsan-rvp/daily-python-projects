# 🏝 Treasure Island Game (Day 02)

A simple text-based adventure game written in Python where the player makes choices to find the treasure.

---

## ❓ What does this project do?

This project is an interactive console game that:
- Shows a story to the user
- Asks the player to make choices
- Uses conditional logic to determine the outcome
- Ends with either winning or losing the game

---

## 📘 Learning Outcomes
In this project, I practiced:

- Using if, elif, and else statements
- Taking and comparing user input
- Writing simple game logic
- Creating a text-based game flow
- Working with multi-line strings (ASCII Art)
