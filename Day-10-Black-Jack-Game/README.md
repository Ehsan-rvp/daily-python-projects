# ♠️ Blackjack Casino Game (Day 10)

A console-based Python implementation of the classic Blackjack game where the player competes against the computer following standard casino rules.

---

## ❓ What does this project do?

This project simulates a Blackjack game where:

- The player and computer are dealt cards
- The player can choose to "hit" (take another card) or "stand"
- The computer follows a fixed rule (draw until reaching 17)
- The winner is determined based on Blackjack rules

---

## ⚙️ Features

- 🃏 Realistic card deck simulation
- 🎲 Random card dealing using Python's `random` module
- 🧠 Score calculation with Ace handling (11 → 1)
- 🤖 Computer logic (auto play until 17)
- 🏁 Full game result handling (win, lose, draw)
- 🔁 Replay system to play multiple rounds

---

## 🧠 Technologies Used

- Python
- Random module
- Functions & nested functions
- Loops and conditionals

---

## 🎯 Learning Objectives

In this project, I practiced:

- Designing a multi-step game logic
- Working with `lists` and random selection
- Implementing game rules (Blackjack mechanics)
- Breaking down logic into functions
- Managing game state (user vs computer)
- Handling edge cases like Blackjack and bust
