# 🏆 Secret Auction Program (Day 08)

A simple Python console application that simulates a secret auction where users can place bids and the highest bidder wins.

---

## ❓ What does this project do?

This program allows multiple users to:

- Enter their name and bid amount
- Keep bids hidden from others
- Determine the highest bidder at the end
- Announce the winner with the highest bid

---

## ⚙️ Features

- 🧑 Multiple bidders support
- 💰 Tracks the highest bid in real-time
- 🔒 Simulates a "secret" auction (clears screen)
- 🏁 Automatically selects the winner
- 🔁 Runs until no more bidders

---

## 🎯 Learning Objectives

In this project, I practiced:

- Using loops (`while`)
- Working with `dictionaries`
- Comparing values to track maximum
- Handling user input
- Controlling program flow with conditions
- Building a simple real-world logic system
