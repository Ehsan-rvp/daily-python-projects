# 💰 Tip Calculator (Day 01)

A simple Python program that calculates how much each person should pay when splitting a bill, including a tip.

---

## ❓ What does this project do?

This project:
- Takes the total bill amount
- Asks for a tip percentage
- Splits the bill between multiple people
- Calculates how much each person should pay

---

## ▶️ How to Run

Make sure Python is installed, then run:

```bash
python main.py
