# 💰 Tip Calculator (Day 01)

A simple Python program that calculates how much each person should pay when splitting a bill, including a tip.

---

## ❓ What does this project do?

This project:
- Takes the total bill amount
- Asks for a tip percentage
- Splits the bill between multiple people
- Calculates how much each person should pay

---

## 📘 Learning Outcomes
In this project, I practiced:

- Taking user input in Python
- Working with numbers and percentages
- Basic arithmetic operations
- Formatting output using f-strings

---

## ▶️ How to Run

Make sure Python is installed, then run:

python main.py
