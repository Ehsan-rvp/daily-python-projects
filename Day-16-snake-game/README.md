# 🐍 Snake Game (Day 16)

A classic Snake game built with Python Turtle graphics where the player controls a snake, eats food, grows longer, and tries to avoid collisions.

---

## ❓ What does this project do?

This project recreates the famous Snake game using Python.

The player can:

- Control the snake using keyboard arrows
- Eat food to grow longer
- Increase the score
- Avoid hitting walls and the snake's own tail
- Track the highest score

---

## ⚙️ Features

- 🐍 Smooth snake movement system
- 🍎 Random food spawning
- 📈 Score tracking
- 🏆 High score saving using a text file
- 💥 Collision detection system
- 🎮 Keyboard controls
- 🖥 Turtle graphics interface

---

## 🧠 Technologies Used

- Python
- Turtle Graphics
- Object-Oriented Programming (OOP)
- File handling
- Loops & collision detection

---

## 🎯 Learning Objectives

In this project, I practiced:

- Building games with `Turtle graphics`
- Using `Object-Oriented Programming`
- Managing multiple classes and files
- Detecting object collisions
- Working with keyboard event listeners
- Saving and reading data from files
- Creating a real-time game loop
