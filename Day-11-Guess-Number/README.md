# 🔢 Number Guessing Game (Day 11)

A simple Python console game where the player tries to guess a randomly generated number between 1 and 100.

---

## ❓ What does this project do?

This game challenges the player to guess the correct number within a limited number of attempts.

The player can choose between:

- Easy mode (10 attempts)
- Hard mode (5 attempts)

After each guess, the game gives hints whether the number is too high or too low.

---

## ⚙️ Features

- 🎲 Random number generation
- 🎯 Difficulty selection system
- 🔁 Attempt tracking
- 📉 High / Low hints
- 🧠 Win & lose conditions
- 🎮 Interactive console gameplay

---

## 🧠 Technologies Used

- Python
- Random module
- Functions
- Conditional statements
- Loops
