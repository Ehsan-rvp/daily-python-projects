# ☕ Coffee Machine Simulator (Day 13)

A simple Python coffee machine simulator that allows users to order drinks, insert coins, and manage machine resources.

---

## ❓ What does this project do?

This project simulates the behavior of a real coffee vending machine.

The machine can:

- Serve different coffee types
- Check if enough ingredients are available
- Process coin payments
- Return change
- Track remaining resources
- Generate machine reports

---

## ⚙️ Features

- ☕ Multiple coffee options (Espresso, Latte, Cappuccino)
- 💰 Coin payment system
- 🧾 Change calculation
- 📦 Resource management system
- 📊 Machine report command
- 🚫 Insufficient ingredient detection
- 🔁 Continuous machine operation

---

## 🧠 Technologies Used

- Python
- Dictionaries
- Nested functions
- Loops and conditions
- Data management

---

## 🎯 Learning Objectives

In this project, I practiced:

- Managing resources with dictionaries
- Building transaction/payment systems
- Working with `nested functions`
- Designing `real-world` program logic
- Handling user input and validation
- Updating system state dynamically
