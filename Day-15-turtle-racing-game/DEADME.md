# 🐢 Turtle Racing Game (Day 15)

A fun Python Turtle graphics game where multiple turtles race across the screen and the player bets on the winner.

---

## ❓ What does this project do?

This project simulates a turtle race using Python's Turtle graphics module.

The player:

- Places a bet on a turtle color
- Watches the turtles race randomly
- Wins if the selected turtle reaches the finish line first

---

## ⚙️ Features

- 🐢 Multiple racing turtles
- 🎲 Random movement system
- 🎨 Different turtle colors
- 🏁 Finish line detection
- 🎮 User betting system
- 🖥 Interactive graphical interface

---

## 🧠 Technologies Used

- Python
- Turtle Graphics
- Random module
- Loops & conditions
- Object-oriented programming concepts

---

## 🎯 Learning Objectives

In this project, I practiced:

- Working with `multiple Turtle objects`
- Using `loops for animation`
- Handling object movement and coordinates
- Creating simple game mechanics
- Managing lists of objects
- Using randomness in gameplay
