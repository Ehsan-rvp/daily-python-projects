# 🎨 Turtle Dot Painting (Day 14)

A colorful dot painting generator built with Python Turtle graphics, inspired by Hirst-style artwork.

---

## ❓ What does this project do?

This project creates a grid-based painting using randomly selected colors and Python's Turtle graphics library.

The turtle automatically:

- Draws colorful dots
- Moves across the screen in rows
- Generates a complete painting pattern
- Uses RGB color values for vibrant artwork

---

## ⚙️ Features

- 🎨 Random color generation from predefined palette
- 🐢 Turtle graphics drawing system
- 📐 Grid-based positioning
- 🌈 RGB color mode support
- ⚡ Fast drawing speed
- 🖼 Automatically generated digital artwork

---

## 🧠 Technologies Used

- Python
- Turtle Graphics
- Random module
- RGB color handling
- Coordinate positioning

---

## 🎯 Learning Objectives

In this project, I practiced:

- Working with the `Turtle graphics module`
- Using `RGB color` systems
- Understanding screen coordinates
- Creating repetitive drawing patterns with loops
- Using random color selection
- Building visual Python projects
