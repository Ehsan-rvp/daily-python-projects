# 🪨📄✂️ Rock, Paper, Scissors Game (Day 03)

A simple console-based Rock, Paper, Scissors game implemented in Python where the player makes choices to compete against the computer.

---

### ❓ What does this project do?
This project is an interactive console game that:
*   Takes player's choice (Rock, Paper, or Scissors) as input.
*   Randomly generates the computer's choice.
*   Displays both player's and computer's choices using ASCII art.
*   Compares the choices based on game rules to determine the winner, loser, or a draw.
*   Announces the outcome of the round.

---

### 📘 Learning Outcomes
In this project, I practiced:
*   Using `if`, `elif`, and `else` statements for conditional logic.
*   Working with the `random` module to generate random numbers.
*   Taking and processing user input.
*   Representing choices with multi-line strings (ASCII Art).
*   Implementing basic game rules and logic.
