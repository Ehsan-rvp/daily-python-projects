# 📈 Higher Lower Game (Day 12)

A Python console game inspired by the popular "Higher Lower" game where the player guesses which celebrity has more social media followers.

---

## ❓ What does this project do?

This game randomly selects two celebrities and asks the player to guess which one has more followers.

The player:

- Compares two celebrities
- Chooses between option A or B
- Earns points for correct guesses
- Continues playing until a wrong answer is given

---

## ⚙️ Features

- 🎲 Random celebrity selection
- 📊 Follower count comparison system
- 🔁 Endless gameplay loop
- 🧠 Score tracking system
- 🔄 Automatic swapping logic
- 🎮 Interactive console interface

---

## 🧠 Technologies Used

- Python
- Random module
- Functions
- Dictionaries & lists
- Loops and conditions

---

## 🎯 Learning Objectives

In this project, I practiced:

- Working with `lists of dictionaries`
- Using random data selection
- Managing game state and score
- Comparing numerical values
- Building reusable helper functions
- Designing continuous game loops
