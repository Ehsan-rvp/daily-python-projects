# 🧮 Python Calculator (Day 09)

A simple command-line calculator built with Python that supports basic arithmetic operations and continuous calculations.

---

## ❓ What does this project do?

This program allows users to:

- Perform basic arithmetic operations (+, -, *, /)
- Continue calculations using the previous result
- Start a new calculation anytime
- Exit the program when finished

---

## ⚙️ Features

- ➕ Addition, ➖ Subtraction, ✖️ Multiplication, ➗ Division
- 🔁 Continuous calculations using previous result
- 🔄 Option to restart calculation
- 🚪 Exit option for ending the program
- 🧠 Uses function mapping with a dictionary

---

## 🧠 Technologies Used

- Python (Functions, Dictionaries, Loops, User Input)

---

## 🎯 Learning Objectives

In this project, I practiced:

- Defining and using functions
- Using `dictionaries` to store and `call functions`
- Handling user input and program flow
- Working with loops (`while`)
- Building a `reusable` and interactive program
- Applying clean logic for continuous calculations
