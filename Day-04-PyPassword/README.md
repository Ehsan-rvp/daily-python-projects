# 🔑 PyPassword Generator (Day 04)

A simple, console-based password generator written in Python. This tool helps users create strong, random passwords by combining letters, numbers, and symbols based on their preferences.

---

### ❓ What does this project do?
This project is an interactive console application that:
*   Prompts the user for the desired number of letters, symbols, and numbers in their password.
*   Randomly selects characters from predefined lists (alphabets, digits, special symbols).
*   Combines and shuffles the selected characters to create a unique and strong password.
*   Prints the generated password to the console.

---

### 📘 Learning Outcomes
In this project, I practiced:
*   Using `import random` for generating random choices and shuffling lists.
*   Working with lists (`[]`) to store and manipulate characters.
*   Implementing `for` loops for repetitive tasks (adding characters).
*   Taking integer input from the user (`int(input())`).
*   String manipulation and concatenation for printing the final password.
*   Developing a practical command-line tool.
