# 🔐 Caesar Cipher Tool (Day 07)

A simple Python program that encrypts and decrypts messages using the classic Caesar Cipher algorithm.

---

## ❓ What does this project do?

This is a console-based application that allows users to:

- Encrypt (encode) a message by shifting letters forward
- Decrypt (decode) a message by shifting letters backward
- Keep numbers, spaces, and symbols unchanged
- Run the program multiple times without restarting

---

## ⚙️ Features

- 🔁 Encode and decode functionality
- 🔢 Supports large shift numbers using modulo logic
- 🧠 Handles wrap-around for alphabet shifting (z → a)
- ✨ Keeps spaces, numbers, and symbols unchanged
- 🔄 Continuous execution until user exits

---

## 🎯 Learning Objectives

In this project, I practiced:

- Using `functions` with parameters
- Working with loops (`for, while`)
- Applying conditional statements (if, else)
- Handling user input
- Implementing a classic encryption `algorithm`
- Using `modulo (%)` to handle large numbers
